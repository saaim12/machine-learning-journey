# Machine Learning Journey

A comprehensive, hands-on repository documenting my progression through machine learning fundamentals, from core mathematical concepts to building real-world predictive models.

---

## Project Overview

This learning journey is structured systematically to build strong ML foundations through:
- **Foundation Modules**: Mathematics, Python libraries (NumPy, Pandas), and visualization
- **Core ML Concepts**: Linear regression, cost functions, and gradient descent optimization
- **Practical Implementation**: Building ML models from scratch and using industry-standard libraries

---

## Repository Structure

### 📚 **Foundational Learning**

#### **NumPy** - Numerical Computing
- `basics.py` - Array creation and manipulation
- `Arthematic_operations.py` - Mathematical operations on arrays
- `Linspace_and_arange.py` - Creating sequences and ranges
- `Numpy_Arrays_methods.py` - Array methods and utilities

#### **Pandas** - Data Manipulation & Analysis
- `How_to_load_file.py` - Loading and exploring CSV datasets
- `Mercedes_Company_dataset.csv` - Sample dataset for practice

#### **Matplotlib** - Data Visualization
- `Basic_plot.py` - Creating and customizing plots for ML insights

#### **Mathematics** - Mathematical Foundations
- Dedicated module for linear algebra, probability, and statistics concepts

---

### 🤖 **Machine Learning Modules**

#### **Linear Regression** - Core ML Concepts

**Labs Structure:**
- **Lab 01: Foundations**
  - `Lab_01_Practice.py` - Linear regression basics with house price prediction
  - `Lab_01.ipynb` - Interactive notebook with explanations

- **Lab 02: Cost Function**
  - `Lab_02.py` - Implementation of cost function
  - `Lab02_Cost_function_Soln.ipynb` - Detailed solution and theory

- **Lab 03: Gradient Descent**
  - `gradient_descent.py` - Implementing gradient descent optimization
  - `Lab03_Gradient_Descent.ipynb` - Visual demonstrations and explanations

**Real-World Project:**
- **Training with Multiple Inputs (Scikit-learn)**
  - `model.py` - Multivariate linear regression using Advertising dataset
  - `Advertising.csv` - Dataset with TV, radio, and newspaper marketing spend vs sales
